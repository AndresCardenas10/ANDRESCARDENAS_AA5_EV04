1) GET /api/salud   [Salud]

  503 Service Unavailable -> La base de datos no esta disponible en este momento

------------------------------------------------------------------------------
2) POST /api/auth/registro   [Autenticación]
------------------------------------------------------------------------------
Que hace: Registrar una cuenta de cliente. Crea un usuario con rol Cliente. La contraseña se guarda cifrada con bcrypt.
Acceso: Público (sin token)
URL de ejemplo: http://localhost:3000/api/auth/registro
Cuerpo: JSON
  - nombre (string, obligatorio): Nombre (máx. 100)
  - apellido (string, obligatorio): Apellido (máx. 100)
  - correo (string, obligatorio): Correo único
  - contrasena (string, obligatorio): Mínimo 8 caracteres, con letras y números
  - telefono (string): Teléfono (opcional)
Ejemplo:
  {
    "nombre": "Laura",
    "apellido": "Gomez",
    "correo": "laura742037@correo.com",
    "contrasena": "Clave1234",
    "telefono": "3001234567"
  }
Respuestas:
  201 Created -> exito: true
  400 Bad Request -> Datos invalidos (el detalle de cada campo viene en "errores")
  409 Conflict -> Ya existe una cuenta con ese correo

------------------------------------------------------------------------------
3) POST /api/auth/login   [Autenticación]
------------------------------------------------------------------------------
Que hace: Iniciar sesión (obtener token JWT). Valida correo y contraseña. Si son correctos responde "Autenticación satisfactoria" y entrega un token JWT que se envía en las demás peticiones con el encabezado Authorization: Bearer <token>. Tras 5 intentos fallidos el correo se bloquea 15 minutos.
Acceso: Público (sin token)
URL de ejemplo: http://localhost:3000/api/auth/login
Cuerpo: JSON
  - correo (string, obligatorio): Correo registrado
  - contrasena (string, obligatorio): Contraseña
Ejemplo:
  {
    "correo": "cliente@demo.com",
    "contrasena": "Demo1234"
  }
Respuestas:
  200 OK -> exito: true
  400 Bad Request -> Debe enviar correo y contrasena
  401 Unauthorized -> Correo o contrasena incorrectos
  403 Forbidden -> Su cuenta esta desactivada. Contacte al administrador
  429 Too Many Requests -> Demasiados intentos fallidos. Espere 15 minutos e intente de nuevo

------------------------------------------------------------------------------
4) POST /api/auth/recuperar   [Autenticación]
------------------------------------------------------------------------------
Que hace: Solicitar código de recuperación. Genera un código de 6 dígitos válido por 15 minutos (se guarda cifrado en usuario.token_recuperacion). Responde igual exista o no el correo. En modo desarrollo el código viene en la respuesta porque el proyecto no tiene servidor de correo.
Acceso: Público (sin token)
URL de ejemplo: http://localhost:3000/api/auth/recuperar
Cuerpo: JSON
  - correo (string, obligatorio): Correo de la cuenta
Ejemplo:
  {
    "correo": "laura742037@correo.com"
  }
Respuestas:
  200 OK -> exito: true
  400 Bad Request -> Datos invalidos (el detalle de cada campo viene en "errores")

23) POST /api/citas   [Citas]
------------------------------------------------------------------------------
Que hace: Agendar cita. Agenda una cita en estado "pendiente". Valida: fecha futura, que el barbero atienda ese día y la cita quepa en su horario, y que ni el barbero ni el cliente tengan otra cita que se cruce (con bloqueo para reservas simultáneas). Guarda el precio aplicado. Si no se confirma a tiempo (60 min por defecto) se cancela sola. Notifica al cliente, al barbero y al administrador.
Acceso: Cliente (a su nombre) o Administrador (indica idCliente)
URL de ejemplo: http://localhost:3000/api/citas
Cuerpo: JSON
  - idBarbero (integer, obligatorio): Id del barbero
  - idServicio (integer, obligatorio): Id del servicio
  - fechaHora (string, obligatorio): AAAA-MM-DDTHH:MM
  - notas (string): Notas para el barbero (máx. 500)
  - idCliente (integer): Solo administrador: cliente de la cita
Ejemplo:
  {
    "idBarbero": 2,
    "idServicio": 8,
    "fechaHora": "2027-03-08T10:00",
    "notas": "Corte bajito a los lados"
  }
Respuestas:
  201 Created -> exito: true
  400 Bad Request -> La fecha y hora de la cita deben ser futuras
  401 Unauthorized -> Debe iniciar sesion (falta el token de acceso)
  403 Forbidden -> Los barberos no agendan citas; las agenda el cliente o el administrador
  404 Not Found -> Barbero no encontrado
  409 Conflict -> El barbero ya tiene una cita en ese horario

  403 Forbidden -> Los barberos no registran pagos
